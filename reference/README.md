# Reference

Research the plan was built from. These are static HTML pages — open them in a
browser; they need no server and work offline.

| File | What it is |
|---|---|
| `scope-board.html` | The 152-feature catalogue with tick boxes. This is the offline copy; the live tick surface is at <https://claude.ai/artifact/2jS1QA467Mhpr4MJX3GqrE>, and `docs/SCOPE.md` is the snapshot the roadmap was generated from. |
| `bdjobs-teardown.html` | Feature-by-feature teardown of Bdjobs, done from a real recruiter account. Includes the finding that matters most: Bdjobs charges for logo display, gives blue-collar postings away free, and its Talent Search holds only 593 caregivers, 315 boiler operators and 2,648 carpenters out of 6.2 million CVs. It has effectively vacated the blue-collar segment. |
| `build-checklist.html` | Build-order checklist from an earlier pass. Superseded by `docs/ROADMAP.md`; kept because it records reasoning the roadmap compresses. |
| `who-can-do-what.html` | Per-role capability matrix for admin, staff, manager, candidate and employer. `docs/ARCHITECTURE.md` lists the capability names; this shows them by role. |

Figures quoted from Bdjobs were read on 1–2 October 2026 and will drift.
